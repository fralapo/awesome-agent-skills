# Glossary

**Abstention** - declining to answer when unsure; a model's alternative to hallucinating (ch9)
**Activation** - the number a neuron holds after its weighted sum and nonlinearity (ch4)
**Agentic misalignment** - harmful goal-directed action by a model with tools in a constructed scenario (ch11)
**Attention** - mechanism where each token takes a weighted sum of values from other tokens (ch7)
**Autoencoder** - network trained to reproduce its input through a narrow bottleneck (ch6)
**Backpropagation** - efficient computation of all gradients by applying the chain rule backward (ch4)
**Base rate** - prior frequency of a condition; ignoring it causes screening paradoxes (ch2)
**Bayes' rule** - posterior proportional to prior times likelihood (ch2)
**Bias (parameter)** - shift added to a weighted sum; sets how much evidence activates a neuron (ch4)
**Binomial distribution** - distribution of successes in n independent trials with one rate (ch2)
**BRDF** - bidirectional reflectance distribution function: how a surface sends incoming light to outgoing directions (ch12)
**Central limit theorem** - sums of many independent contributions tend to a Gaussian (ch2)
**Chain of thought** - intermediate reasoning text produced before the answer (ch8)
**Chain rule** - sensitivity of a composite equals the product of sensitivities along the chain (ch1)
**Contamination** - benchmark items or answers present in training data (ch9)
**Convolution** - flip-and-slide weighted overlap of two functions; adds random variables (ch2, ch6)
**Cost (loss) function** - single number measuring how badly the parameters fit the data (ch4)
**Cross-entropy** - average code length when data follow P but the code assumes Q; standard classification and language loss (ch3)
**Distillation** - training a small model on a large model's output probabilities (ch3)
**Dot product** - sum of products of components; alignment of two vectors (ch1)
**Eigenvector / eigenvalue** - direction a linear map only stretches, and the stretch factor (ch1)
**Embedding** - vector representing a token or concept (ch7)
**Entropy** - expected information per symbol; lowest average code length (ch3)
**Episodic memory (in RL)** - stored experiences reused to estimate values and allow drastic adjustments (ch5)
**Feed-forward block (MLP)** - per-token expand, clip, project block holding most parameters (ch7)
**Gradient** - vector of partial sensitivities; its negative points downhill (ch1, ch4)
**Gradient descent** - repeated small steps against the gradient (ch4)
**Greedy decoding** - always choosing the most probable next token (ch7, ch8)
**Hallucination** - fluent output not supported by facts or the prompt (ch10)
**Hamming code** - error-correcting code whose parity checks spell the position of a flipped bit (ch3)
**Inductive bias** - built-in assumptions of a learner (ch5)
**Information (bits)** - minus log2 of an event's probability (ch3)
**Key / query / value** - the three vectors per token used by attention (ch7)
**L1 / L2 regularization** - penalties on absolute or squared weights (ch5)
**Laplace transform** - transform using growing/decaying complex exponentials; turns linear differential equations into algebra (ch3)
**Masking** - setting future positions to minus infinity before softmax (ch7)
**Mini-batch** - small random subset used per gradient step (ch4)
**Monte Carlo estimate** - average of f at random samples divided by the sampling density (ch12)
**Next-event estimation** - connecting each path vertex directly to a light sample (ch12)
**Outcome reward** - reward based on the final answer (ch8)
**Overfitting** - fitting training noise; poor on new data (ch5)
**Path tracing** - rendering by randomly sampling light paths (ch12)
**Poisson equation (reconstruction)** - recovering a map from its gradients (ch12)
**Post-training** - stages after pre-training: preferences, verified rewards, domain environments (ch8)
**Pre-training** - next-token prediction on a vast corpus (ch8)
**Process reward** - reward or score for each reasoning step (ch8)
**Pruning** - removing units with limited accuracy loss (ch5)
**Reward hacking / specification gaming** - achieving a high reward in a way the designer did not intend (ch10)
**ReLU** - function returning max of zero and the input (ch4, ch7)
**Residual connection** - adding a block's output to its input (ch7)
**Rule of succession** - estimate of a rate by adding one success and one failure to the counts (ch2)
**Scaling law** - predictable relation between loss and model size, data and compute (ch8)
**Self-consistency** - sampling several answers and taking the majority (ch8)
**Softmax** - exponentiate and normalise scores to probabilities (ch7)
**Sparse autoencoder** - wide, sparse-code autoencoder used to extract features from activations (ch6, ch11)
**Stochastic gradient descent** - gradient descent on mini-batches (ch4)
**Superposition** - storing many nearly orthogonal features across fewer dimensions (ch7, ch11)
**Temperature** - divisor applied to scores before softmax controlling randomness (ch7)
**Test-time compute** - computation spent while answering (ch8)
**Token** - text chunk the model reads and predicts (ch7)
**Unembedding** - final matrix mapping the last vector to vocabulary scores (ch7)
**Weak learner** - model only slightly better than chance, combined in boosting (ch4)
