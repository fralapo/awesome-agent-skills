# Graphic Designer: Cheatsheet

## Numbers and Rules at a Glance

| Topic | Rule |
|---|---|
| Body size from headline | headline ÷ fixed factor (75 pt ÷ 5 = 15 pt); larger divisor for display posters |
| Weights | use 1–2; skip a step (regular + extra bold, not bold) |
| Typefaces | 1 per piece, 2 only if well paired |
| Alignment | one shared edge (usually flush left); anchor centred blocks with lines |
| Justified text | avoid in narrow columns; rivers = failure; if forced reduce size in ½–¼ pt steps |
| Last line | never a single word; never start a paragraph with the previous last word |
| A4 print grid | 3 mm bleed; 15 mm margins (bottom ≈ 25 mm); 4 columns, 5 mm gutter; 8 rows, 5 mm gutter |
| Caption example | 8 pt on 10 pt leading |
| Grid choice | 1 col books; 2 magazines; 3+ news/web; modular for mixed content |
| Displacement on type | strength ≈ 15–50 keeps words readable |
| Pixelate for line effect | cells ≈ 50–200 px; crystallize ≈ 130–220 |
| Line thickening | maximum filter 1–3 px |
| Posterize (portrait lines) | 4–20 levels (fewer = fewer lines) |
| Logo stress test | favicon size, one colour, reversed, embroidery, animation |
| Sizes per phrase | max 2 sizes, 2 colours; new size at least double or half; three units of measure (big, medium, small) |
| Secondary copy | about 50-60 percent of the headline as a starting point |
| Groups | space between groups > space inside groups; try 1/3 to 2/3 instead of equal gaps |
| Near-tangent | align exactly or separate clearly; repeat an overlap or remove it |
| Headline line | about 7 words max; hard return not indent; real punctuation |
| Functional text | about 80-90 percent plain and legible |
| Review order | objective, read order, technical soundness; one dimension per pass |
| Logo reproduction | compact lockup; business-card test with contact info; print at size; widen thin white gaps |
| Logo tests | aesthetic, application, scale, fatigue, taste, moodboard (30-50 year brands) |
| Contrast depth | foreground darker/brighter, background lighter/lower contrast; add contrast locally, not globally |
| Packaging rank | what it is, product name, brand; check 6 sides and shelf distance (about 6 ft) |
| Lockup hierarchy | name dominates; tagline lower and lighter; script paired with a lighter type; monoline re-balanced after scaling |
| Finishes | spot varnish = partial gloss on matte; glossy reads cheaper than matte plus metal accent |
| Portfolio | 3-5 pro-level pieces; best first; first 20-30 seconds decide |
| Spacing scale | one base unit and multiples: 4 / 8 / 16 / 32, or 12 / 24 / 48; reuse values across unrelated places |
| Column maths | width = (canvas - outer margins - total gutters) / columns; 1200 px, 60 px margins, 6 columns, 24 px gutters = 160 px |
| Columns by need | 6 for halves and thirds; 12 for finer banner control; 10 flexible; widen the span, do not shrink type, when copy grows |
| Print margins | about 0.5 to 1 in (2.5 cm) plus about 0.5 cm bleed; buffer lines inside module lines |
| Baseline grid | body leading = base unit; headline = multiple (14 pt body, 28 pt headline) |
| Hierarchy levels | hook (largest) / secondary (clear gap, ch10: 50-60 percent of headline) / finisher (body, action); hook is not always the key information |
| Entry-proof-action | entry top left, under about 7 words; proof = stat + close crop; action on F/Z path with a white-space moat and one accent |
| Isolation | exactly one tactic: unique hue, unexpected scale or subtle motion; compare on three artboards |
| Primary button | about 1.5-2x the height and width of standard text elements |
| Movement levels | direct guidance, hierarchy flow, layered routes, implied motion, disruption, temporal flow |
| L-I-F-T | leverage point, internal rhythm, friction and flow, transferability (thumbnail, dark/light, mobile, print) |
| Image ratio | one aspect ratio per family (for example 3:2) |
| Colour test | grayscale; 50 and 25 percent; contrast checker; colour-blindness preview; CMYK proof |
| Tint / tone / shade | hue + white / + grey / + black |
| Palette roles | action, communicator, support, neutral, anchor, feedback; map each against digital, print, social, motion |
| Shadow / texture | shadow about 30 percent black, multiply, 30-50 percent opacity; texture in overlay or soft light |
| Type ramp | body 11 x 1.618 = 18 / 29 / 47, or x 1.414 = 16 / 23; weights 400 / 600 / 800 |
| Text numbers | print body 10-12 pt (not below 9 pt untested); web 15-25 px; leading 120-145 percent; 45-90 characters per line; H1 180-200 percent of body, H2 130-150 percent |
| Decision budget | about 4 decisions per poster; 10-second test with a fresh viewer |
| Scale test | about 1920 / 768 / 280 / 64 px (or print equivalents) |
| Logo viewing | step back 1.2-1.8 m (4-6 ft); two spacing versions (tight for large, loose for small) |
| Ownability grid | 20 category logos, same size, names hidden |
| Logo presentation | max 3 systems in an identical template plus one on-brief stretch concept |

## Logo Types
Lettermark (long names) · Wordmark (startups, short names) · Brandmark (language-free) · Combination (flexible) · Emblem (authority) · Mascot (personality, hard to keep timeless).

## Shape Psychology
Square/rectangle = strong, reliable · Circle/oval = community, friendship · Angled line = speed, motion · Triangle = strength, stability · Straight edges = man-made/industrial · Curves = natural/living.

## Brutalist Poster Ingredients
Striking image · Bold type (heavy extended + characterful secondary + neutral grotesque for utility text) · Small details · Cohesion (overlap, repeated accent, same image treatment) · Texture (scanned grunge, displacement edges, overlay noise).

## Experimental Type Moves
Outline → cut/join · Serif + sans complementary halves · Vector blend · Add/subtract shapes · Skew/stress change · Constraint sprint · General-to-specific font choice · Physical process then scan.

## Critique Phrasing
Observation (what is on the page) -> reason (what it does to the viewer) -> criterion or sketched fix. Define adjectives with a bad-to-good slider. Criteria for professionals, sketched fix for learners or repeated notes.

## Hand-offs
Idea or insight unclear → creative director · Direction, references, style family, identity rules → art director · Screens, flows, accessibility numbers → UX/UI. Client taste discovery, strategy-to-direction, stylescapes, rebrand decisions → art director. Problem framing, concept formulas → creative director.
