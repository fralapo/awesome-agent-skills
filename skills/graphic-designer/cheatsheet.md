# Graphic Designer: Cheatsheet

## Numbers and Rules at a Glance

| Topic | Rule |
|---|---|
| Body size from headline | headline ÷ fixed factor (75 pt ÷ 5 = 15 pt); larger divisor for display posters |
| Weights | use 1–2; skip a step (regular + extra bold, not bold) |
| Typefaces | 1 per piece, 2 only if well paired |
| Alignment | one shared edge (usually flush left); anchor centred blocks with lines |
| Justified text | avoid in narrow columns; rivers = failure; if forced reduce size in ½–¼ pt steps |
| Last line | never a single word; never start a paragraph with the previous last word |
| A4 print grid | 3 mm bleed; 15 mm margins (bottom ≈ 25 mm); 4 columns, 5 mm gutter; 8 rows, 5 mm gutter |
| Caption example | 8 pt on 10 pt leading |
| Grid choice | 1 col books; 2 magazines; 3+ news/web; modular for mixed content |
| Displacement on type | strength ≈ 15–50 keeps words readable |
| Pixelate for line effect | cells ≈ 50–200 px; crystallize ≈ 130–220 |
| Line thickening | maximum filter 1–3 px |
| Posterize (portrait lines) | 4–20 levels (fewer = fewer lines) |
| Logo stress test | favicon size, one colour, reversed, embroidery, animation |

## Logo Types
Lettermark (long names) · Wordmark (startups, short names) · Brandmark (language-free) · Combination (flexible) · Emblem (authority) · Mascot (personality, hard to keep timeless).

## Shape Psychology
Square/rectangle = strong, reliable · Circle/oval = community, friendship · Angled line = speed, motion · Triangle = strength, stability · Straight edges = man-made/industrial · Curves = natural/living.

## Brutalist Poster Ingredients
Striking image · Bold type (heavy extended + characterful secondary + neutral grotesque for utility text) · Small details · Cohesion (overlap, repeated accent, same image treatment) · Texture (scanned grunge, displacement edges, overlay noise).

## Experimental Type Moves
Outline → cut/join · Serif + sans complementary halves · Vector blend · Add/subtract shapes · Skew/stress change · Constraint sprint · General-to-specific font choice · Physical process then scan.

## Hand-offs
Idea or insight unclear → creative director · Direction, references, style family, identity rules → art director · Screens, flows, accessibility numbers → UX/UI.
