# Chapter 10: Layout and Type Refinement Rules

## Core Idea
Ch02 and ch03 set the structure (grid, ratio, weights, one edge). This chapter is the refinement pass: the small, repeatable checks that turn a competent layout into a resolved one. Most amateur-looking work is not wrong in structure; it is almost-aligned, almost-contrasted and almost-grouped. The unifying rule: **an element either hits the line or clearly misses it; a size is either clearly bigger or clearly smaller; a group is either clearly together or clearly apart.**

## Procedure: A Refinement Pass (in order)
1. **Group into masses** and check they differ in size. Equal elements with equal gaps read as predictable.
2. **Reduce size and weight** of secondary things; smaller elements open negative space and relieve crowding.
3. **Tune the gaps between groups** until they feel intentional (a one-third to two-thirds split instead of equal spacing). The space between groups must exceed the space inside them.
4. **Anchor strays**: an element that does not fit the main axis gets a second axis (a baseline or a rotated line); add one small anchoring mark (rule, dot, tick) to connect an isolated group.
5. **Zoom in** and check every alignment and equal measure; print at actual size.
6. **Remove or add**: too simple, add a graphic or a grid line; too complicated, delete elements.
First-pass positions are sketches; expect many small adjustments.

## Alignment and Edges
- **Near-tangents** (close but not aligned, or touching by accident) look like errors. Align exactly or separate clearly. The same holds for an element that almost aligns with a grid line.
- Align type baselines to a graphic edge and cap height to block edges.
- In text-heavy layouts register to the baseline, usually the strongest horizontal line.
- **Hanging punctuation**: quote marks sit outside the text edge so the text aligns to the margin.
- Numbers in columns align flush right (as in addition); running text flush left.
- Keep numerals no taller than the shortest element in their row.
- Centre optically, not only mathematically; a diagonal or oblique baseline needs visual correction. A supporting line that drifts off the axis of a centred block reads as careless; centre credits and secondary lines exactly.
- Hard cut-off edges that leave a sliver of type look accidental: crop letters enough that they still read, or not at all. Leave room so text is not clipped at the edge.

## Scale and Contrast Rules
- Define **three units of measure**: big, medium, small. Judge the negative space between them.
- At most **two point sizes, two colours and one case or baseline scheme per phrase**; each phrase is one connected thought. A new size should be at least double or half of the others; near-equal sizes look like a mistake.
- Choose **one dominant contrast** (one very large element against very small text). Do not set a single word in two sizes.
- Secondary copy at roughly 50 to 60 percent of the headline is a workable starting point (compare the ratio method in ch03).
- A single extra colour or a band behind primary information creates hierarchy without adding elements; secondary information can be textural.
- Italic is for one word, not a paragraph; italicising one number in regular text makes the emphasis ambiguous.
- Thin light colour on white needs thicker strokes to survive print.
- A big light display over fine dark body copy works (type over type); keep the body legible.

## Type Detail Rules
- Paragraph starts: a hard return (space) rather than an indent in modern layouts.
- Use real punctuation (apostrophe not prime marks).
- Break a split word at syllables so it still reads. Fix widows by adjusting copy length with the writer.
- Keep a headline line to about seven words.
- Leading: tighten so related lines form one block; wide gaps turn them into separate elements. Treat space between lines as a design element and close it when it reads as a hole.
- Letter spacing: a deliberate rhythm device in display headlines, not random.
- Indent a second headline line to create a second level without changing size or colour.
- Use a genuinely extended or condensed family; a stretched regular face looks distorted. Do not use condensed widths for body text.
- Orient vertical type so it reads top to bottom, the direction the eye travels.
- No underlines on non-link text.
- Functional text: roughly 80 to 90 percent plain and legible; expressive treatment suits short phrases.
- Pair sans headline with serif body (or the reverse) for contrast, choosing faces with personality rather than generic ones. A stray default typeface in one piece of a family set is a defect.
- Flush-left on a clear grid; centred text reads old-fashioned unless it is a short strong display. Drop caps and thick-plus-thin double rules also read as dated in modern layouts.
- Use realistic placeholder copy, not the same line repeated; realistic details (price, date, barcode, legal line) make spec pieces feel real.

## Systems and Rhythm
- Repeat one small device (a dot, an angle, a line, a triangle) at small, medium and large scales for callouts, anchors and pointers.
- **Repeated overlap reads as intent; a single overlap reads as a mistake.**
- Pair rigid blocks with organic shapes; let one element break the grid.
- **Figure-ground**: let some type and shapes overlap others so depth reads, but do not stack too many tricks (pattern plus offset plus graphic) on one page.
- Do not fill the page with boxes; heavy separators trap white space.
- Treat tension devices (forcing lines to touch) with a balance check; they can become too heavy.
- Trapped spaces (small awkward gaps between type and a line) are fixed with tracking, size, or letting the type overlap the line.
- Over a textured background semi-transparent overlays look dirty; use an opaque fill or a cleaner ground.
- Decorative registration marks and accent lines that tie to nothing should go.
- Master pages and a consistent header and footer system are set before production.

## Common Mistakes
- Equal point sizes everywhere.
- Floating small items with no anchor.
- Placeholder shapes or left-over details that connect to nothing.
- Late additions (an extra text block beside the logo) that break the alignment.
- Rigid alignment for a message that should feel urgent, or loose arrangement for one that should feel stable.

## Checklist
- [ ] Three units of measure; no near-equal sizes
- [ ] Gaps between groups larger than inside groups
- [ ] No near-tangents; strays anchored
- [ ] Numbers, quotes and baselines aligned
- [ ] Overlaps either repeated or removed
- [ ] Checked zoomed in and at real size
- [ ] Real punctuation, syllable breaks, no widows
