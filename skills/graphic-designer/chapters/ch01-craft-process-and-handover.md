# Chapter 01: Craft Process and File Handover

## Core Idea
The graphic designer turns a brief and a direction into finished work. The craft habits that separate professional from amateur output are: justify every element, alternate between detail and context, plan for how the work will be used and aged, and hand over files that others can continue without asking questions. Concept and visual direction belong to other roles; this chapter covers how execution is run well inside them.

## Frameworks Introduced
- **Why-before-what at element level**: every element must answer "why this colour, why this shape, how does it direct the eye, how does it support the message?" Decoration that carries no purpose is removed; "it looks cool" is not a reason.
- **Purposeful irregularity**: perfectly aligned, symmetric, evenly spaced layouts read as generic templates. Add rhythm, tension, controlled imbalance or breathing room (a product image overlapping key type, a thin line linking product to price, a faint text logo blended into a corner).
- **Micro/macro switching**: alternate between micro (type size, curves, alignment tweaks) and macro (behaviour on mobile, print and social, scale across markets and time). Staying zoomed in is a beginner trait.
- **Execution pre-mortem**: before delivery ask where it could fail: logo misread, palette failing on different backgrounds, type unreadable on small screens. Test those cases.
- **Raise, don't override**: when execution shows that the concept or direction does not work in the format, report it to its owner with evidence and options.
- **Component analysis** (for studying references): break artefacts into components (type, image, figure, white space, hierarchy, colour); isolate with outlines and blocked areas; group like with like; layer comparable pieces with transparency to see where elements habitually sit; measure the share of the format used by type. Discard unproductive angles; visualise findings with charts and scaled mock-ups.

## Handover Hygiene
- Name layers clearly, group by function (not only appearance), organise folders, structure smart objects.
- **Stranger test**: could someone who has never seen the project finish or edit it without asking a question?
- Add a top-level readme (fonts, colour codes, export instructions); about five minutes, signals professionalism.
- Design for the future: a mark should hold up in motion, on merchandise, in 3D, not only on today's website.

## Rules and Numbers
- Large, bold, uppercase type tends to read as aggressive, small regular-weight type as calm; rounded playful lettering reads as friendly; these are craft levers once the emotion is set by the art director.
- First accessibility check: simulate impairment (blur, vignette, low contrast), then validate with real users. For low-vision readers desaturate very bright colours and pick out forms with high-contrast outlines (fully saturated and full black-and-white both performed worse). Numeric thresholds live in `ux-ui-expert`.

## Common Mistakes
- Staying zoomed in on details while the format or lifespan is unchecked.
- Decorative motifs and edge ornaments that carry nothing.
- Silently changing the concept or direction instead of reporting the problem.
- Delivering a flattened file with unnamed layers.
