# Exercise Science and Programming: Cheatsheet

Educational, not medical or coaching advice. Figures are dated rules of thumb from trials with limits; "position" = practitioner judgment, not consensus. Chapter references in brackets.

## Defaults (when you know nothing else about the person)
| Variable | Default | Range / note |
|---|---|---|
| Hard sets per muscle per week | about 10-20 | 10+ beats fewer (consensus); higher is contested; start low, add on signals [ch03] |
| Sets per muscle per session | about 4-8 | below 2-4 wasteful, above about 8-10 quality drops (position) [ch03] |
| Frequency per muscle | 2 per week (2-4 range) | beyond 2 small benefit at equal volume [ch04] |
| Reps | most sets 6-15 | 5-30+ works near failure; 3-6 for strength skill [ch05] |
| Effort | 0-3 reps in reserve (RPE 7-10) | failure sparingly; beginners misjudge reserve [ch05] |
| Rest | 2-3 min compounds; 1-2 isolation | under 1 min costs growth at equal sets [ch07] |
| Tempo | about 2 s down, control, full range | 0.5-8 s per rep similar; over 10 s worse [ch07] |
| Progression | double progression, logged | add load when top of range reached on all sets [ch07] |
| Deload | reactive on signs, or about every 4-8 weeks | easy means easy; half the sets [ch08] |
| Sleep | 7-8.5 h | under-sleepers misjudge impairment [ch09] |

## Where to Start
| Situation | First move |
|---|---|
| "No gains" | Check hard-set quality, progression logs, food, sleep; then add a few sets if recovered [ch03, ch09] |
| Run down, performance falling | Look for leading indicators; reduce volume or deload; fix sleep [ch09] |
| Plateau on a main lift | Verify it is a real stall (3-4 weeks, like for like, recent anchor) [ch07] |
| Beginner stops adding weight every session | Add volume, slow the progression to weekly [ch11] |
| Cannot decide between two options | Equal on average; pick by preference, joints, time; test for weeks [ch01] |
| Claim sounds too precise | Ask for the proxy, the population and the confidence range [ch12] |
| Pain or injury | Stop, see a professional; `biomechanics-and-rehab-reasoning` [ch10] |

## Contested topics: one-line positions
| Topic | Position A | Position B |
|---|---|---|
| Volume ceiling | inverted U, about 10-20 sweet spot | no clear ceiling found; more can help |
| Failure | needed or helpful for advanced | not needed; costs recovery |
| Effective reps | only the last ~5 reps count | gradient; model over-precise |
| Periodization (size) | helps | variation, not the method |
| Squat bar | low bar loads hips more | little difference, choose what fits |
| Form | postures matter for safety | dose and preparation dominate |
| Deloads | scheduled | reactive |

## Rep and RIR conversions (approximate)
RPE 10 = 0 RIR; RPE 9 = 1 RIR; RPE 8 = 2 RIR; RPE 7 = 3 RIR. Estimates are less accurate above about 8-10 reps. A chart that maps reps and RPE to a percentage of a max is chart-specific.
