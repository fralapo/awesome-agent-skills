# Chapter 04: Directing, Reviewing and Presenting

## Core Idea
An art director gets quality from other people's hands. That means briefing with criteria instead of pixels, reviewing against the stated direction and not against personal taste, routing each problem to the role that owns it, and presenting directions in a way that keeps client expectations stable.

## Briefing a Graphic Designer
- State the feeling, the audience, the references, the rules (palette logic, type voice, imagery and texture language, layout character), the red lines, and the touchpoints in priority order.
- Give the concept in one sentence (from the creative director) and the reason behind the direction.
- Let the designer propose craft solutions; ask for several quick variants and compare them, instead of polishing one.
- Provide a way to say no: invite the designer to report when the direction fails in a format.

## Reviewing Work
1. Read it first as the audience would, for a few seconds: which emotion arrives?
2. Compare with the one-emotion statement and the system rules.
3. Check hierarchy, consistency with the family, and the three most different formats.
4. Look for decoration without purpose and for single bold moves that carry the piece.
5. Route feedback by owner: idea problem → creative director; craft problem (alignment, hierarchy, type, file quality) → graphic designer; usability or accessibility problem → UX/UI designer.
6. Give feedback as criteria ("calmer, more space, one accent") rather than solutions ("make it 12 px lighter").
7. When the same note returns twice, the direction or the brief is unclear: fix that, not the file.

## Presenting Directions to Clients
- Show about three routes; each tied to the positioning it serves.
- Expectations peak when you open well and drop when objections arrive. Concede small points, close the meeting, and avoid endless counter-proposals that keep expectations oscillating.
- A simple idea may be found quickly; persuading many stakeholders is the long part, so plan for several revision rounds.
- Layout and alignment can change real outcomes (a ballot with staggered response marks can mislead voters), so anticipate human reaction, not only taste.
- Over-deliver on process: finish earlier than promised, offer one more concept than agreed, and present with care.

## Accessibility and Testing Hand-offs
- Ask the graphic designer for a first impairment simulation (blur, vignette, low contrast); for low-vision readers desaturate very bright colours and use high-contrast outlines. Real-user validation and numeric WCAG thresholds belong to `ux-ui-expert`.
- Ask for a stranger test on files: could someone edit the project without questions?

## Common Mistakes
- Reviewing by personal taste and changing the direction in every round.
- Feedback delivered as pixel instructions.
- Sending an idea problem to the designer, or a craft problem to the creative director.
- Presenting a single option, or many options with no recommendation.
