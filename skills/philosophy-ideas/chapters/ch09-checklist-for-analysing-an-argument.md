# Chapter 09: Checklist for Analysing an Argument

## Core Idea
In this model, analysing an argument is a fixed routine: **identify the claim, find the premises, test each link, face the strongest objection, state what the reply costs, and say what remains open**. Run it on a thesis of your own as well as on someone else's.

## 9.1 The ten steps
1. **State the thesis in one sentence.** If you cannot, the argument is not yet an argument.
2. **List the premises** in plain words, including the hidden ones. Ask for each: stated, assumed, or smuggled?
3. **Check the form.** Does the conclusion follow if the premises are true (validity)? Is there a dilemma (find the third option) or a regress (ask why it must stop)? (ch01)
4. **Check each premise.** Which is the weakest? What evidence supports it? (ch02)
5. **Find the bridge between is and ought**, if there is one, and state it. (ch01, ch02, ch05)
6. **Run the self-application test.** Does the position apply to itself without collapse? (ch01)
7. **Name the strongest objection** and its best reply. Do not accept a reply that only restates the thesis.
8. **State the cost of the reply.** Each position pays somewhere: costs are information. (ch04, ch05)
9. **Check the evidence type.** Is it a calculation, an observation, a thought experiment, testimony or authority? How reliable is that type here? (ch02, ch08)
10. **State what is open** and mark each claim as established, contested (position) or speculative.

## 9.3 Quick fallacy and move list
- **Genetic fallacy**: judging a belief only by its psychological origin (ch01).
- **Self-defeating relativism**: if all views are equally true, the view that some are better is also true (ch01).
- **Is/ought slide**: a fact used for a value without a bridge (ch01).
- **Appeal to the age's alternatives**: "it must be X" when only X was imagined (ch01).
- **Inverse gambler's fallacy**: inferring more trials from a lucky outcome (ch08).
- **Linear intuition**: treating nonlinear growth as linear (ch01, ch08).
- **Label shift**: using a word with a loaded meaning to carry a conclusion (ch07).
- **Mistaking a map for the territory**: a model or picture standing in for the thing (ch03, ch04).
- **Quantum randomness as freedom**: randomness is not control (ch03).
- **Equating regress-stopping with God**: the first cause is not automatically a person (ch03).

## 9.4 Worked mini-example
Claim: "morality needs God, so an atheist has no basis for morality."
1. Thesis: without God, no objective moral duties.
2. Premises: duty requires a commander; societies are unreliable commanders; a perfect being is a reliable one. Hidden: duty must be a command.
3. Test: the divine-command dilemma (ch05, 5.8): if goodness is commanded, it is arbitrary; if independent, God is not its source.
4. Strongest objection to the objection: God's nature is the standard.
5. Cost of that reply: it relocates the question to why that nature is good.
6. Open: whether objective duties can rest on harm and reasons.
The outcome is not that the claim is false but that it has a named hidden premise and a priced reply.
