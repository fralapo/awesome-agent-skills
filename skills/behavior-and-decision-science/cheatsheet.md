# Behavior and Decision Science: Cheatsheet

Figures are approximate and not verified; re-test. "Position" = interpretation, not evidence. "Contested" = active dispute or replication difficulty. Chapter references in brackets. No clinical advice.

## Where to Start
| Situation | First move |
|---|---|
| Judging how good an experience was | Separate lived moments from the remembered story; check ending and peak [ch01] |
| Predicting your future happiness | Imagine a normal week, not the standout feature [ch01] |
| Feeling behind or inferior after scrolling | Ask who the reference group is and what they chose to show [ch01] |
| Motivation gone after a few weeks | Tie action to a value, take a small first step, treat bad days as data [ch07] |
| Making a long promise or rule | Expect your future self to differ; add humility and an exit [ch01] |
| Feeling certain | Ask what you would expect to see if you were wrong [ch01] |
| Overloaded, too many tasks | Accept you will not finish; do the next fastest useful task [ch02] |
| Strong emotion in the body | Ask what physical cause could explain it; reinterpret arousal as preparation [ch03, ch04] |
| Reading emotion from a face | Context decides meaning; do not trust confident readings [ch03] |
| Pre-event nerves | Practise under real conditions; write worries down; reappraise [ch04, ch06] |
| Worry about what you cannot change | Two columns: up to me / not up to me [ch04] |
| Need to remember a list | Meaningful hooks, memory palace of absurd images [ch05] |
| Vivid but unverifiable memory | Seek independent corroboration; confidence is not accuracy [ch05] |
| Skilled performance falters under watching | Do not attend to steps; practise with an audience [ch06] |
| Want to build or change a habit | Log cue and reward, keep them, replace the routine, give an immediate reward [ch07] |
| Constant phone reaching | Tech-free times and zones; count reflexive urges [ch07] |
| Stuck on a creative problem | Fix a frame, make many poor attempts, write what you know [ch08] |
| Group brainstorming flat | Individuals first, then converge [ch08] |
| Hot argument | Loop: listen, restate, check, then respond [ch09] |
| Someone argues in bad faith | Name the move: dodge, twist, wrangle, flood [ch09] |
| Partner conflict about small things | Look for the understory [ch09, ch10] |
| Fear of being disliked | Choose values you control; tolerate disapproval [ch10] |
| A project failed | Which kind of failure? Hypothesis? Was it small? [ch11] |
| Big choice with a bad-case fear | Write a decision record; size the bet so a bad run is survivable [ch13] |
| Too many options, cannot choose | Set criteria before browsing; accept good enough; keep the set small [ch13] |
| Strong view after a short read | Name your depth of study; read the primary source and one dissenting one [ch14] |
| Spending keeps rising with income | Name the reference group; fix the share of any raise for savings before it arrives [ch15] |

## The Saturation Routine (ch02)
1. Name it: "I am saturated."
2. Accept: "I will not finish everything."
3. Ask: "What is the next task I can finish fastest?"
4. Finish it; repeat; drill in ordinary days.
5. Rule of thumb for planning: capacity estimate minus two.

## Habit Loop Worksheet (ch07)
| Field | Question |
|---|---|
| Cue | Time, place, people, emotion, preceding action? What is constant over a few days |
| Craving | What do I want when the cue arrives? |
| Routine | What do I do? |
| Reward | What do I actually get: energy, a break, company, relief? |
| New routine | Same cue, same reward, new behaviour |
| Immediate reward | Something enjoyable right after, not later |
| Social support | Who expects me, who says "I believe you can"? |

## Looping (ch09)
1. Listen for what matters most to them.
2. Say it back in your own words.
3. Check: "Is that right? Am I missing anything?"
4. Only after "yes, exactly": ask the next question or add your view.
Common understories: power and control; respect and recognition; care and concern; stress and overwhelm.

## Intelligent Failure Test (ch11)
New territory, pursuit of a goal, hypothesis-driven, as small as possible. If any fails, it is basic or complex failure: prevent or fix, do not celebrate.
