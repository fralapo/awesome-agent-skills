# Brand Strategy & Storytelling: Cheatsheet

## Decision Rules

| If... | Then... | Ch |
|---|---|---|
| The client asks for "a logo / a brand" | Ask which feeling customers should have and why now; run discovery before any deliverable | 01, 02 |
| You are about to say "branding" | Check you shape strategy and experience too; otherwise say "identity design" | 01 |
| The brief has vague adjectives | Ask for an example of each; reduce to an opposing pair | 02 |
| The brief names a fix ("we need X") | Probe for the symptom behind it; ask "what else" until empty | 02 |
| An inquiry asks only for a price on a deliverable | Treat as cold; qualify problem awareness first | 02 |
| The audience is "everyone" | Force either/or choices until you can spot one person in a crowd | 03 |
| The claim cannot be number one in 1-2 years | Add a dimension (topic + audience or region) | 03 |
| The offer is good but looks like the category | Commodity: invert, or change about 3 percent | 03 |
| The offer is different but weak | Gimmick: fix quality first | 03 |
| Your plot on attribute sliders matches a competitor's | Redo with forced choices; take an extreme on at least one attribute | 03 |
| Customers cannot retell the story | Shorten it, add one true specific detail, put it on the pack or first screen | 05 |
| The backstory would sell better if embellished | Do not; find the true detail instead | 05 |
| A big talk or pitch is coming | Prepare about 3 stories, rehearse beats aloud, cut bullets before stories | 05 |
| Buyers cannot picture the result | Add documented real proof; no stock or AI images posed as real | 08 |
| A profile headline lists personality tags | Rebuild: role + years, industries, product type, focus, methods | 06 |
| The voice sounds like a committee | Rewrite from one person's belief; run the tone filter | 04 |
| A line explains everything | Cut to a hook; move the explanation to the subhead and body | 04 |
| The brand line is two adjectives | Replace with a noun that is your truth, or a known-unknown twist | 04 |
| A story is a list of events | Replace "and then" with "but/instead"; add a want and an obstacle | 05 |
| A paragraph has no nameable emotion | Rewrite; hold relief for later | 05 |
| The story has many takeaways | Keep one; cut every detail that does not serve it | 05 |
| The brand "has no enemy" | Name the practice or belief you oppose | 03, 05, 06 |
| Persona and private self drift apart | Shrink the gap or drop the persona | 06 |
| Posting seems to do nothing after 3 posts | Wait for about 12 on one topic; check inflow and signals together | 07 |
| A viral hit is the goal | Reframe to relationships; track repeat engagement | 07 |
| A case study has no outcome | Get one number or a stated qualitative result; rewrite the title | 08 |
| A page underperforms | Diagnose offer and traffic before rewording | 09 |
| An email test shows a winner | Run A/A first to measure noise | 09 |

## Numbers (rough rules of thumb, test locally)
| Topic | Figure |
|---|---|
| Brand ladder | 4 rungs; track share at the top yearly |
| Brand vs getting the word out | about 30 / 70 effort split as a starting rule |
| Brand attributes | collect freely, reduce to 2 (a pair), keep top 5 if words stall |
| Positioning line | draft about 15 versions, keep 1, reduce to 3 short phrases |
| Ownership test | number one in 1-2 years |
| Niche test | pick one person out of a crowd |
| True fans | fans x profit per fan = income (1,000 x 100 = 100,000) |
| Trust | 3-5 repeated touches; roughly 7 hours / roughly 11 brand interactions cited as rough targets |
| Organic horizon | plan 3 to 6 months |
| Minimum run | about 12 posts on one topic before judging |
| Iterations | about 4 to 8 before a piece is refined |
| 30-30-30 | 30 experiments, repeat 2-3 winners, refine for 30 days each |
| Carousel | about 8 content slides, max 10; one CTA |
| Cold email reply | low single digits per hundred contacts is normal |
| Story checks | 4 yes/no: personal, feeling, struggle, one takeaway |
| Case study summary | 3 parts: challenge, outcome, results |
| Portfolio | best work first; role stated; headlines alone tell the story |
| Name test | write the address 4 times; say it to 10 people |
| Story set | about 3 stories per product or audience |
| Impression-to-sale | about 1-4 percent, so reach matters |
| Sprint | 30 minutes work / 10 minutes break for writing practice |

## Quick Formulas
- **Claim**: [offer] for [specific group] so that [result], without [barrier].
- **Offer statement**: developing [specific offering] to help [specific audience] solve [problem] with [secret sauce].
- **Brand core**: one word + one enemy + one rallying cry.
- **Story circle**: comfort, want, unfamiliar, adapt, heavy price, learn, return changed.
- **Story components**: character + authentic emotion + specific moment + specific details.
- **Headline**: role + years, industries, product type, focus, methods.
- **Story**: want + obstacle + gap + one takeaway; normal / explosion / new normal.
- **Hero arc**: origin / defining moment / transformation / opposition.
- **Personal story**: personal story + emotional response + one clear takeaway.
- **Message layers**: hook > subhead > body > one CTA.
- **ADAP**: attention, detail, desired state, call to action.
- **AIDA**: attention, interest, desire, action.
- **Outreach**: something they would like + personality + evidence you know them.
- **Sales piece**: problem, benefit, objections, action.

## Red Flags
- "Brand" used as a synonym for logo or deliverable list.
- Two-adjective positioning ("quietly fierce").
- Claims with no proof plan.
- Slogan the company cannot deliver.
- Story with no opposition.
- Case study with a client name as title and no result.
- Vanity metric (reach, likes) used as the only success measure.
- Persona who is "everyone".
- Copy tested on colour before message.
