# Glossary

**Account model** - ledger design that stores a balance per address (ch01)
**Address** - identifier derived from a public key, used to receive funds (ch01)
**Airdrop** - free token distribution; income for tax in the Italy snapshot (ch09)
**AMM (automated market maker)** - pool plus formula replacing an order book (ch07)
**Anonymity set** - number of participants mixed with in a collaborative transaction (ch01)
**APR / APY** - simple annual rate / rate including reinvestment (ch07)
**Bearer value** - value controlled by whoever holds the signing key, with no company between holder and value (ch12)
**Block explorer** - public tool to inspect transactions on a ledger (ch03)
**Bridge** - mechanism moving assets between chains; a frequent exploit target (ch07)
**Central-bank digital currency** - digital money issued as a claim on a central bank; design choices include offline use, holding limits and privacy (ch12)
**Change output** - the part of a spent output sent back to the sender (ch01)
**Chain analysis / clustering** - inferring common ownership from on-chain patterns (ch01)
**Claim on an issuer** - balance that is a debt of a bank, company or central bank to the holder; reversible and protected only as far as the issuer is (ch12)
**CoinJoin** - collaborative transaction mixing several users' inputs (ch01)
**Cold storage** - keys kept on a device never connected to the internet (ch03)
**Collateral / LTV** - asset pledged for a loan / loan-to-value ratio (ch07)
**Compounding** - applying each period's return to the previous result; a daily rate compounds to a much larger annual figure (ch10)
**Convenience spread** - gap between buy and sell prices charged by fast or kiosk channels; paid on entry and exit (ch12)
**Cost basis** - acquisition cost per lot (ch09)
**Creator fee** - percentage of each trade paid to a token's issuer, set in its contract (ch13)
**Custodial** - a third party holds the keys (ch03, ch05)
**Death spiral** - self-reinforcing collapse of an algorithmic peg (ch07)
**Derivation path** - rule that turns a seed into a specific address format (ch03)
**Difficulty** - how many leading zeros a valid block hash needs (ch02)
**Disinflationary** - supply grows more slowly over time but never shrinks (ch02)
**Double spend** - using the same coin twice (ch01)
**ETN / ETP** - exchange-traded note (debt claim) / exchange-traded product (ch06)
**Fee (per byte)** - price of block space, independent of the amount sent (ch01)
**Freeze authority** - a contract right to block addresses from moving a token; a control to know about (ch13)
**Funding rate** - periodic payment between long and short perpetual-futures positions that keeps the contract near spot; its sign shows which side pays (ch11)
**Halving** - reward cut in half every 210,000 blocks (ch02)
**Hash function** - one-way function mapping input to a fixed-size number (ch01)
**Hash rate** - total computing power securing a proof-of-work chain (ch02)
**Hardware wallet** - dedicated device that holds and signs with keys (ch03)
**Impermanent loss** - value gap between a pool position and holding the tokens (ch07)
**Lightning** - network of payment channels over the base ledger (ch04)
**Liquidation** - forced sale of collateral when a loan crosses its threshold (ch07)
**Liquidation cascade** - sequence of forced closes that push price and trigger further closes (ch11)
**Liquidity-provider token** - receipt for a deposit in a pool; whoever holds it can withdraw the deposit (ch13)
**Liquid staking** - receipt token for staked assets (ch07)
**Long-term holder** - holder of coins unmoved for a long period; the cut-off varies by provider (ch11)
**Mempool** - waiting area for unconfirmed transactions (ch01)
**Memecoin** - token whose value rests almost entirely on attention and community, with minimal stated use (ch13)
**Mint authority** - right to create new units of a token; if kept, supply can be diluted (ch13)
**Multi-signature** - k-of-n signatures required to spend (ch03, ch04)
**Nonce** - number changed by miners to search for a valid hash (ch02)
**Offline payment** - payment accepted without checking the shared record; relies on hardware, limits and later reconciliation (ch12)
**Oracle** - source of external data for a contract (ch07, ch09)
**Open interest** - open derivative contracts not yet closed; a measure of commitment, not turnover (ch11)
**Passphrase** - optional extra secret that selects a different wallet (ch03)
**Peg** - target exchange rate of a stablecoin (ch07)
**Pool depth** - amount of each asset in a liquidity pool; determines how much can be sold near the quoted price (ch13)
**Promised return** - advertised rate that must be compounded and sourced before it is compared (ch10)
**Proof of reserves** - attestation of assets, incomplete without liabilities (ch05)
**Proof of work / stake** - ordering secured by computing cost / by locked capital (ch02, ch07)
**Realised price** - aggregate value of coins at the price each last moved, divided by supply (ch11)
**Replace by fee** - replacing an unconfirmed transaction with a higher-fee one (ch01)
**Rug pull** - a creator withdraws liquidity or uses supply controls, leaving other holders with unsellable tokens (ch13)
**Satoshi** - 1/100,000,000 of the main unit (ch04)
**Seed phrase** - 12-24 words encoding the master secret (ch03)
**Slashing** - penalty destroying part of a stake (ch07)
**Slippage** - execution price worse than quoted because of trade size (ch07)
**Smart contract** - code on a ledger executing conditions automatically (ch07)
**Sniper** - automated buyer that acts in the first blocks after a token's pool opens (ch13)
**Spurious correlation** - correlation of trending series without causation (ch08)
**Stablecoin** - token aiming to track a reference currency (ch07)
**Step-up** - tax option resetting cost basis for an upfront payment (ch09, Italy, snapshot 2025)
**Testnet** - network with valueless coins for rehearsal (ch03)
**Token unlock** - scheduled release of previously locked supply, which can add sale pressure (ch13)
**UTXO** - unspent transaction output (ch01)
**Valuation without cash flows** - pricing an asset that pays nothing by expected demand; no anchor in its own accounts (ch08)
**Value levy** - percentage-of-value yearly tax on foreign-held assets (ch09, Italy, snapshot 2025)
**Vesting** - schedule under which insiders' tokens become tradable over time (ch13)
**Whitelist (withdrawal)** - list of pre-approved destination addresses (ch03, ch10)
