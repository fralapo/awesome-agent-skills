# Cheatsheet

All sizes in pt on a 1920×1080 px, 16:9 canvas (pt ≈ px). Scale proportionally on other canvas sizes.

## Canonical Type Scale (Ch04, Ch03)
| Role | Size | Notes |
|---|---|---|
| Cover / statement / menu headline | 80–160 | 120–160 when one word fills the width; cover display text up to 200–300 |
| Quote | ~80 | low end of the statement range; 96–128 is too much |
| Message title on a content slide | 64–88 | key sentence ~80, max 3 lines, 2–3 words in accent |
| Title on list / data / chart slides | 40–48 | the slide also holds a list, table or chart |
| Subtitle under a large title | 48–64 | balanced against the title |
| Body text | 24–32 | minimum 32 when read across a classroom/large room |
| Data descriptions / secondary text | 24 | grey paragraph under a message title 24–32 (28 typical) |
| Key numbers | ≥56 | 56 in dense data slides |
| Hero numbers | 120–200 | caption 24–32 |
| Labels / eyebrows above titles | 20–28 | ~24, increased tracking |
| Sources, footnotes, footer, axis labels | 18–20 | bar-chart category labels up to 28 with no Y axis/grid |
- Prefer multiples of 8 (24, 32, 40, 48, 56, 64, 80, 120, 160, 200); 28 and 18–20 accepted. The scale is a guide, not a law.
- Never mix recipe rows inside one slide; keep a large ratio between adjacent levels.

## Spacing, Margins, Guides (Ch03, Ch02)
| Item | Value |
|---|---|
| Side margins | ≈4% of width (≈80 px) |
| Top margin | ≈6–8% of height (≈65–90 px) |
| Bottom margin with footer | ≈110–120 px (bottom guide higher than the others) |
| Guides minimum | 4 margin guides + vertical and horizontal centre guides, in the master |
| Columns | 2 for little content; 3–4 for a series of points; optional 4-column grid |
| Text column width | 1/2 to 2/3 of the slide, never full width |
| Paragraph space | 32 pt (48 pt between key sentence and paragraph; ~8 pt after a title line) |
| Space rule | inside a group < between groups; title↔body > body line↔line |
| Footer text box | inner margins 0, top-aligned, inside the bottom margin |
| Placeholders | resize shape to fit text, top-anchored, inner margins 0 |
- Space comes from space before/after and box margins, never from empty returns.
- Margins are not mandatory numbers; consistency is.

## Line Spacing & Line Length (Ch04)
| Setting | Value |
|---|---|
| Big titles | 0.8–0.95 (0.9 typical), slightly tightened tracking |
| Body | Line spacing "Multiple" 1.1–1.2 in PowerPoint (PowerPoint's single spacing is already ≈1.2× the font size, so 1.1–1.2 multiple ≈ 130–140% of the size; Keynote single ≈1.27×) |
| Never | 1.5 (lines separate and read like a list) |
| Projected slides | 40–50 characters per line |
| Documents / emailed decks | 50–80 characters per line |
| Bullets | 3 ideal, 5 max per slide, max 3 lines each; 6 → two columns of 3 with a 1–1.5 pt grey divider |

## Slide-Type System (Ch02, Ch11)
| Type | Job | Background |
|---|---|---|
| Cover | contextualize/introduce; designed last | main colour or image |
| Agenda / index | ~4 macro-chapters | light (or as cover) |
| Break / section | chapter marker, number + title, max 2 levels | secondary colour or darker desaturated tint |
| Focus | one phrase or number to remember; held longer | contrasting (e.g. near-black) |
| Content | the majority; fixed frame, varied layouts | off-white |
| Back cover | call to action, contacts, main concept | identical to the cover |
- Rhythm: cover/main → content/light → break/secondary → closing = cover. Rigid in 2–3 h trainings, freer in 5–10 min talks.
- Check the rhythm in sorter/grid/light-table view.

## Colour Roles & Palette Recipe (Ch05, Ch11)
| Role | Colour |
|---|---|
| Background | near-white / off-white (never #FFFFFF) |
| Text, cover, break slides, back cover | near-black or deep tint (~90% darker than base) |
| Accent | base hue (0%): titles' key words, icons, dividers, page number |
| Data tints | 20/40/60/80/90% steps for charts and illustrations |
- Recipe: one main colour (topic + feeling) → tint/shade generator → keep base, ~90% darker, ~90% lighter, plus steps. Invert light/dark for a dark version.
- 2–3 colours + neutrals; max ~4 meaningful theme colours; one accent; no rainbow.
- Safe harmony: neutral triad (white + black/grey + one colour). Complementaries never small and adjacent.
- Red: accent on neutrals, white text on red, reserved for negative data in charts.
- Always check contrast on the real slide. Pick from theme colours, never "recent colours".

## Image Functions & Overlays (Ch06)
| Function | Treatment |
|---|---|
| Evocative | large, half slide or more, full bleed |
| Anchor icon | one per list point, palette colour |
| Descriptive | real product/views/gallery, same aspect ratio |
| Explanatory | screenshot/diagram with zoom, circle or callout |
| Overlay | Value |
|---|---|
| Black rectangle | semi-transparent over the full image |
| Gradient overlay | black 0% transparency at text → 100% where empty |
| Coloured veil | 4-colour diagonal gradient, opacity 85–90%, over a desaturated photo |
| Darken | −40% brightness for white text on a portrait; −10% under glass |
| Blur | sharpness −100% for cover backgrounds, plus lower brightness |
| Gallery thumbnails | brightness −60 |
- Full bleed needs ≥1920 px wide (a 640×426 image is far too small). No watermarks, no search-engine images.

## Shadows (Ch06, Ch03)
| Case | Setting |
|---|---|
| White cards on white | opacity 10–20% |
| Blur | proportional to distance: ~20 at a contained distance, ~50 at double |
| PowerPoint card shadow | offset down, transparency 85–90%; tested: 90%, size 100%, blur 48 (8 is too sharp) |
| Dark background | black shadow ~40% |
| Main-colour light background, blue shadow | ~44% |
| Glass panel | centred shadow, transparency ~60–74% |
- Never 100% opacity, never the preset; one standard shadow per template; lighter background → lighter shadow.

## Icons (Ch06, Ch11)
- One library, one style, one stroke weight; never mix outline/filled or mono/multicolour.
- One icon per concept, always with text; never as filler.
- Recolour to the palette; not too small relative to their text; on palette circles/squares or white rounded boxes with soft shadow.
- No suitable icon → split content or use images.

## Charts & Tables (Ch07)
| Rule | Value |
|---|---|
| Per slide | one chart or one table |
| Title | chart title or slide title, never both; takeaway in slide title |
| Focus | other bars/series ~80% transparency; focus solid |
| Data label on focus | ~32 pt bold; otherwise ~18 pt above the line |
| Axis labels | 18–20 pt grey |
| Line series | ~4 pt, square caps, no shadow |
| Source | 18 pt, medium grey, on the bottom margin |
| Table lines | horizontal only, thin light grey; heavier under header; no fills, no verticals, no outer border |
| Cell margins | L/R 0; T/B ≈0.5–1 cm; numbers right-aligned |
| Yes/no | brand colour + check vs grey + X; no traffic lights |
| Timeline | one date per slide (max ~3); line ~1.5–2 pt |
- Never 3D. Remove legend (one series), Y axis (with data labels), duplicates, decimals.
- Percent axis: decimals (0.82), max 1.0, major unit 0.1.

## Animation Timings (Ch08)
| Element | Duration |
|---|---|
| Objects | 0.2–0.5 s (0.3 preferred) |
| Line drawing | 0.5 s |
| Fade-and-move | 0.3–0.5 s, very short distance |
| Transitions | 0.5–1 s (max 1.5) |
| Fade between duplicated state slides | ~0.3 s |
| Morph | ~1 s (0.5–0.7 small moves; 1–1.5 large shapes) |
| Delays (stagger) | 0.1–0.2 s (0.2 on text) |
| Bridge slide | auto-advance 0 s |
| Loops | 5–10 s (path 8–15 s), auto-reverse |
- Default style: fade. On click for anything named aloud. One style deck-wide.
- Active item 100% opacity, inactive ~30%.

## Pre-Flight Checklist Before Presenting (Ch01, Ch09)
- [ ] Full-screen presentation mode, never edit view or PDF scrolling
- [ ] Presenter remote (or phone/iPad) ready
- [ ] Presenter view with speaker notes; online, share only the audience window
- [ ] PDF backup exported and checked (animations lost, overlaps broken)
- [ ] Tested on the target software, version and machine
- [ ] Fonts embedded or system/Google fonts
- [ ] View-only link saved offline for online decks
- [ ] Rehearsed alone, with people, in the venue
- [ ] Cover proofread
- [ ] Webinars: key light, accent light, decent microphone

## Redesign Audit (Ch10)
| Area | Check |
|---|---|
| Organization | slide types present (cover, breaks, focus, content, back cover with CTA); sequence; background rule per type; ~4-entry index |
| Text | one message; largest element = message; no duplicates; equal item lengths; hierarchy label → title → body; left alignment; column width |
| Color | number of colours; contrast; brand fit; role per slide type; no rainbow |
| Style | one font family; consistent shapes, corners, shadows; no clashing styles on one slide |
| Resources | image quality and coherence; one icon set; diagrams/tables rebuilt natively; no pasted foreign styles |
- Fix order by impact: structure → text → colour → style → resources. Keep–Kill–Change before touching.

## Slide-Count Heuristics (Ch01, Ch09)
- Slide count is an output: script → select slide moments → design → rehearse → count.
- Common rule of thumb ~15 slides per 10 min; 33 slides for a 20-min thesis defence worked.
- A visual slide can last ~10 s; a diagram much longer. Reinforcing slides fast, deep-dive slides slow.
- Pitch deck ≈13 slides (page numbers optional). Respect any imposed cap without overloading.
- More slides ≠ longer talk: the speaker sets the duration.
- Time budget: 10–20-min talk ≈4–5 h; full client deck ≈1 month part-time.
