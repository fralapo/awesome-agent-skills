# Glossary

**AI champion** — a trained colleague per department who keeps teaching, collects requests and shares working examples (ch02)
**Anonymisation** — replacing identifying details with placeholders before text leaves your control, keeping the mapping inside (ch03)
**Assessment** — a questionnaire on level, resistance, software and repetitive tasks, run before and after training (ch02)
**Atomic task** — a task small enough to be described, timed and automated alone, from a task audit (ch01)
**Baseline** — the measured state before the change, against which a pilot is compared (ch05)
**Company brain** — a deliberately built layer of context, data, skills, transcripts and automations that assistants use, with permissions and sources (ch03)
**Contradiction sweep** — questions asked of a knowledge assistant on purpose to expose conflicting source documents (ch06)
**Cost per completed task** — total cost to finish a task including retries and review, the right basis for comparing models (ch07)
**Dormant lead reactivation** — contacting an old list with personalised, template-approved messages and classifying replies (ch04)
**Global intent** — a request handled at any step of a conversation, such as "I want a person" or "I want an appointment" (ch04)
**Guardrail (screening step)** — a check before the agent for jailbreak patterns, personal data, secrets or links; lowers risk, does not remove it (ch06)
**Human at both ends** — a person defines the task and owns the checked result, with the machine in the middle (ch01)
**Impact/complexity grid** — a two-axis ranking of candidate tasks; quick wins are high impact, low complexity (ch01)
**Key user** — a respected, curious colleague who knows the work and carries adoption in a department (ch02)
**Linked-file brain** — knowledge kept as readable files with links that the assistant follows, as opposed to search-only retrieval (ch03)
**Lock-in** — dependence on one vendor's models, formats or storage that makes switching costly (ch03, ch07)
**Ontology (data)** — a description of tables, fields and their meaning that lets questions be turned into queries (ch03)
**Precedence rule** — which source wins when documents disagree (newer, more specific, named authority) (ch06)
**Prompt injection** — instructions hidden in data (an email, a page) that a model may follow (ch06)
**Quick win / big swing** — a high-impact, low-complexity project versus a high-impact, high-complexity bet (ch01)
**Second brain (personal)** — a per-person folder with role, goals, style, projects, processes and skills that an assistant reads each session (ch02)
**Skill** — a written procedure an assistant loads when relevant; a living standard operating procedure (ch02)
**Task audit** — mapping work into areas and atomic tasks with frequency, time, risk and data needed (ch01)
**Template (messaging)** — a pre-approved message with variables required by business messaging platforms for company-initiated contact (ch04)
**Text-to-query** — turning a question into a database query so numbers come from data, not model memory (ch03)
**Uncensored (unfiltered) model** — a model with refusals reduced; not smarter, to be used only on systems you own or with written permission (ch06)
**Vendor-neutral (model-agnostic)** — designed so the model can be swapped without rebuilding context, skills or data (ch03)
**Workflow (fixed)** — a path fixed in code with model calls at named points, as opposed to an agent that chooses the path (ch01)
