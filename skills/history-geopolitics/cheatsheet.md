# History and Geopolitics: Cheatsheet

Dates and figures are estimates unless marked. "Position" = judgment, not fact. Chapter references in brackets.

## Where to Start
| Situation | First move |
|---|---|
| "Why did X fall?" | Name what ended; list causes by role (underlying, amplifier, trigger); label evidence [ch01, ch08] |
| One cause offered | Ask which other stresses existed and whether neighbours under the same shock survived [ch02] |
| Climate explanation | Check proxy type, scale, dating, and whether earlier equal shocks were survived [ch01, ch03] |
| Destruction layer | Fire proves fire, not enemy; look for texts, weapon types, hoards [ch01] |
| Silence in records | List readings and what each predicts [ch01] |
| Modern analogy requested | Apply the five-step rule and list disanalogies [ch07] |

## Evidence Types: What They Show and Do Not
| Type | Shows | Does not show |
|---|---|---|
| Burn layer, arrowheads | Violent event, rough date | Who, why |
| Ruler's inscription | How the ruler wished to be seen | Accurate events |
| Letters, administrative tablets | Requests, shortages, relations | Outcome |
| Pollen, sediment cores | Plants, erosion, floods, droughts (local) | Society's response |
| Tree rings | Year-by-year rainfall or growth (regional) | Harvests directly |
| Ice cores | Volcanic and solar signals, storminess | Regional temperature at the site |
| Bone isotopes, skeletons | Diet, stunting, disease | Cause of death |
| Shipwreck cargo | Trade reach, essential loads | Dependence |
| Epic, saga, folk tale | Memory and attitude | Sequence of events |
| Monument counts | Rise and fall of royal capacity | Reason |

## Models and What to Look For
| Model | Look for |
|---|---|
| Stress and trigger [2.1] | Several strains before the event |
| Surplus and complexity [2.2] | Non-producers' share, effort per unit food |
| Cascade [2.3] | Clustered failures, repairs that break something else |
| Feedback / minimum size [2.4] | Maintenance lapses, reused stones, choked canals |
| Fragility from tuning [2.5] | Design range vs actual extreme |
| Simplification [2.6] | Squatters, reuse, pilgrimage, relocation |
| Survivors [2.7] | What differed, plus luck |
| Process vs event [2.8] | Last dated item vs life afterwards |

## The Four Cases at a Glance
| Case | Shape | Main contested point | Best-supported element |
|---|---|---|---|
| Classic Maya [6.1] | City by city over about a century | Drought's role and size | Local erosion, malnutrition, monument decline |
| Angkor [6.2] | Slow decline plus sieges | Order: system failure or leaving | Tree-ring drought/flood swings; sieges |
| Late Bronze Age [6.3] | Decades, many sites | Who the Sea Peoples were; iron | Destruction layers; trade dependence |
| Greenland [6.4] | Decline over decades | Why adaptation stopped | Cooling, lifeline cut, diet shift |

## Role Labels for Causes
| Role | Meaning | Example |
|---|---|---|
| Underlying | Weakness present for long | Thin surplus; single lifeline |
| Amplifier | Makes a shock worse | Deforestation; deadly alliance web |
| Trigger | Event that starts the break | Drought; a raid; a port burnt |
| Symptom | Result mistaken for a cause | Late fortifications |

## Evidence Grades [ch08]
A multiple physical agree; B one strong physical; C interested document; D inference; E legend.

## Hedging Vocabulary
| Say | When |
|---|---|
| "The record shows" | Physical find |
| "This suggests" | Inference with named steps |
| "According to the account" | Narrative |
| "Historians disagree on" | Debated; name positions |
| "Unclear" | Evidence gave no clear answer |

## Analogy Check [ch07]
Name mechanism; match variables; list 3 disanalogies; give a test; say what history cannot tell.
