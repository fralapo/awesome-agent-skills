# Glossary

**1% low** - frame rate of the slowest one percent of frames; shows stutter an average hides (ch05)
**3-2-1 rule** - three copies, two kinds of media, one off site (ch06)
**Airflow (positive pressure)** - more intake than exhaust, so dust enters only through filters (ch04)
**All-in-one cooler** - sealed liquid loop with pump, radiator and fans (ch04)
**Bandwidth (memory)** - bus width times memory speed; how fast data reaches the cores (ch03)
**Bottleneck** - the stage that sets overall speed for a given workload and setting (ch02)
**Cache** - small fast memory near the core holding recently used data (ch02)
**Credential stuffing** - replaying leaked passwords on other sites (ch06)
**Cross-load regulation** - how well a supply holds each rail when loads are unbalanced (ch01)
**Frame generation** - inserting interpolated frames between real ones (ch03)
**Galvanic corrosion** - corrosion where two metals meet in a conducting liquid, clogging cooler loops (ch04)
**Hybrid cores** - mix of large and small cores; the scheduler assigns threads (ch02)
**Inrush current** - brief surge when a supply is switched on (ch01)
**IPC** - instructions completed per clock cycle (ch02)
**Joule heating** - heat equal to current squared times resistance, the cause of burnt connectors (ch01)
**Latency (memory)** - wait between a request and the data arriving (ch02)
**Noise band** - run-to-run variation inside which differences are not evidence (ch05)
**NPU** - low-power accelerator for low-precision AI math; TOPS figures are not comparable (ch03)
**Platform (power supply)** - the underlying design that several brands relabel (ch01)
**Quantisation** - storing model weights at lower precision to save memory (ch03)
**RAID** - drives combined for speed or redundancy; not a backup (ch04, ch06)
**Ripple** - fast residual wobble on a supply rail (ch01)
**Silicon lottery** - sample-to-sample variation between chips of one model (ch05)
**Spatial upscaler** - enlarges one finished frame; no motion data (ch03)
**Spill-over (graphics memory)** - using main memory over the slower bus when graphics memory is full (ch03)
**Temporal neural upscaler** - uses several frames, motion data and a trained network (ch03)
**Thermal cycling** - repeated heating and cooling that fatigues solder joints (ch04)
**Throttling** - a chip lowering its clock to stay within temperature or power limits (ch04)
**Transient (power)** - very short spike in demand above average draw (ch01)
**VRM** - voltage regulation stage near the processor and card (ch04)
