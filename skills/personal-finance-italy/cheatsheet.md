# Personal Finance Italy: Cheatsheet

Educational concepts, not investment, tax or legal advice. **Every figure below is a snapshot (Italy, year in brackets); re-check against the rule in force before relying on it (ch12).** "Position" = contested view. Chapter references in brackets.

## Where to Start
| Question | First move |
|---|---|
| Net return of a bond or deposit? | IRR on dated net flows; then compare net, not gross [ch02, ch01] |
| Why is this yield high? | Find the risk being paid: credit, call, currency, subordination, lock-up [ch03] |
| Which tax rate applies? | Instrument and issuer: government 12.5%, most others 26% [ch02, ch04] |
| Can this loss offset that gain? | Check category: miscellaneous income offsets miscellaneous income; fund gains are capital income [ch04, ch05] |
| Accumulating or distributing ETF? | Deferral favours accumulation; difference small short term [ch04] |
| Foreign broker: what do I file? | Monitoring section, gains section, capital-income section, payment form [ch06] |
| Pension fund worthwhile? | Gross-up the deduction, check employer match, TFR and horizon [ch07] |
| Fixed or variable mortgage? | Option value of fixed with portability; check the maximum payment [ch08] |
| Heirs and securities? | No income tax at death; funds keep original basis (heir pays 26% on sale), miscellaneous-income instruments generally take declared value (verify) [ch09] |
| Is this a scam? | Unsolicited, urgent, irreversible, escalating fees [ch11] |
| Is the rule current? | Date, tax year, payment year; source ladder [ch12] |

## Formulas
| Quantity | Formula |
|---|---|
| Net yield | gross x (1 - t) |
| Government-equivalent gross | net / 0.875 |
| Price estimate | 100 - (yield - coupon) x years |
| Accrued interest | coupon x days elapsed / days in period |
| Duration effect | price change ~ -modified duration x yield change |
| Annualised return | (final/initial)^(1/n) - 1 |
| Monthly rate from annual | nominal/12 (Italian mortgage convention); (1 + i)^(1/12) - 1 only if i is an effective annual rate |
| Loan payment | P x r / (1 - (1 + r)^-n) |
| Wealth levy (foreign assets) | value x 0.2% x days/365 |
| Cashback break-even spend | annual fee / cashback rate |
| Bookmaker margin | 1 - 1 / sum(1/odds) |

## Scam and Safety Checks
- Unsolicited offer, urgency, irreversible payment, escalating fees: stop [ch11].
- Call back on a number you looked up yourself; two confirmations on the same channel are one.
- Guaranteed return above about 10% is not real; low-risk guaranteed returns track risk-free rates.
- Prepaid "tax" or "fee" to release winnings is a fraud signal.
- Regulated intermediaries appear in official registries.
