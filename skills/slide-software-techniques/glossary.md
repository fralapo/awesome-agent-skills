# Glossary

**After Previous** — animation start option that begins an item once the previous one ends (Ch03)
**Align & Distribute** — Arrange commands that line up objects and space them evenly between the first and last; the single highest-value command (Ch02)
**Anchor** — vertical text alignment inside a box; top-anchored titles keep their first line still as text grows (Ch02)
**Animation** — motion applied to one object: Entrance, Emphasis, Exit or Motion Path (Ch03)
**Animation Painter** — copies a whole animation set from one object to another, like Format Painter (Ch02, Ch03)
**Animation Pane** — panel listing every animation on a slide with its effect options, start, duration, delay and order (Ch03)
**Autofit** — text-box behaviour when content grows: Shrink text on overflow, Do not Autofit, or Resize shape to fit text (Ch02)
**Auto-Reverse** — effect option that plays an animation backwards after it finishes; core of loops (Ch03)
**Bubble chart percentage** — X Y (Scatter) Bubble chart used as a pie alternative, with Y min 0 to cut bubbles into half circles (Ch02)
**Change Picture** — replaces an image while keeping its size, crop shape and position (Ch02)
**Change Shape** — Edit Shape command that swaps a shape for another preset while keeping text and formatting (Ch02)
**Chart Template** — saved chart formatting reusable via Insert > Chart > Templates (Ch01)
**Combine** — Merge Shapes operation that joins shapes and removes their overlap; used for window frames (Ch02, Ch03)
**Cover-rectangle mask** — rectangle in the background colour stacked over text or images to hide them until Morph moves them out (Ch03)
**.crtx** — PowerPoint chart-template file, saved in the computer's Chart Templates folder rather than inside the presentation; one per chart type (Ch01)
**Custom spacing** — Google Slides line-spacing option to set values such as 1.1–1.2 instead of presets (Ch04)
**Delay** — wait before an animation starts; 0.1 s for fast population, 0.2 s steps for a perceived sequence (Ch03)
**Do not Autofit (Non adattare)** — autofit mode where the box keeps its size whatever is typed; for cards, pills and tabs (Ch02)
**Duotone** — recolouring a photo with theme or palette colours to keep it inside the palette (Ch02, Ch04)
**Easing** — acceleration/deceleration of a motion (Smooth Start/End); fast moves without it look like a slam (Ch03)
**Emphasis animation** — highlights an object already on the slide (colour, glow, grow, spin) (Ch03)
**Expressive motion** — animation that conveys the brand or topic; the hardest function of motion (Ch03)
**Fade and Move (Dissolvi e sposta)** — Keynote build used at 0.3–0.5 s with a very short distance (Ch04)
**Format Painter** — copies formatting; double-click it to apply repeatedly, Esc to stop (Ch02)
**Functional motion** — animation that directs focus: one point at a time, enlarge, recolour, move (Ch03)
**Glassmorphism** — frosted-glass card made with a blurred background picture fill and a card filled with the slide background (Ch03)
**Group text: All paragraphs at once** — effect option making a box and its text appear together (Ch03)
**Guides** — non-printing lines set on the Master to define margins, centre and columns; invisible in slideshow (Ch01)
**Hide Slide** — keeps a slide in the file but out of the show; preferred to deleting spare slides (Ch02, Ch05)
**HTML export** — Keynote export to index.html plus assets that runs with animations in a browser but without presenter notes (Ch05)
**Indent levels** — bullet levels of the Master body placeholder, each formattable as a distinct text style (Ch01)
**Interactive PDF** — non-linear PDF with clickable index, home icon, prev/next arrows and external links (Ch04, Ch05)
**Layout** — slide template under the Master that holds placeholders for one slide type and cascades to slides using it (Ch01)
**Line Draw (Tracciamento linea)** — Keynote build that draws a line, typically 0.5 s (Ch04)
**Link to original presentation** — Google Slides paste option that keeps a copied slide synced via Update (Ch04)
**Loop** — repeating background motion: motion path, Auto-Reverse, Repeat Until End of Slide, 5–10 s (Ch03)
**Magic Move (Spostamento magico)** — Keynote's object-matching transition, applied to the first slide (Ch03, Ch04)
**Mask with Selection** — Keynote command that masks an image with a drawn shape whose points stay editable (Ch04)
**Master → Layout → Slide hierarchy** — settings on the Master cascade to layouts, layouts cascade to slides; manual edits override both (Ch01)
**Match & Move (Dinamiche combinate)** — Canva's object-matching transition, ~1 s, best with one or two moving objects (Ch04)
**Merge Shapes (Unisci forme)** — Union, Combine, Fragment, Intersect, Subtract operations on selected shapes (Ch02)
**Morph (Morphing)** — PowerPoint transition that animates every object common to two slides; applied to the second slide (Ch03)
**Motion path** — invisible line an object follows, preset or custom; green start, red end (Ch03)
**Native-format delivery** — handing over in the destination tool's format (.pptx/.potx, Keynote file, live link) plus a PDF backup (Ch05)
**Near-black** — very dark grey used instead of pure #000000 for text (Ch01)
**On Click** — animation start triggered by the presenter; reserved for the item being named (Ch03, Ch05)
**Park off-slide** — placing objects outside the slide so Morph can bring them in or take them out (Ch03)
**Pass-through slide** — identical auto-advancing slide that dissolves a group so Morph doesn't fall back to a fade (Ch03)
**Placeholder** — layout container for text, picture or chart content that reflows when the layout changes (Ch01)
**Play in Window** — Keynote mode that plays the show in a window so presenter view stays available during calls (Ch04, Ch05)
**.potx** — PowerPoint template file; double-clicking it creates a new untitled .pptx so the template is never overwritten (Ch01)
**Presenter view** — presenter-only screen with current and next slide, notes and timer (Ch05)
**Print each stage of builds** — PDF export option that shows build sequences step by step instead of stacked images at once (Ch05)
**Recolor** — picture colour option applying theme colours; absent in Keynote (Ch02, Ch04)
**Remote** — clicker, smartphone or iPad used to advance slides away from the keyboard (Ch05)
**Repeat last action** — Ctrl+Y / Cmd+Y re-applies the last formatting to the current selection (Ch02)
**Resize shape to fit text (Adatta dimensioni forma al testo)** — autofit mode where the box follows its content; for free text and placeholders (Ch01, Ch02)
**Selection Pane (Riquadro di selezione)** — panel to select, rename, reorder, lock and hide objects (Ch02)
**Shrink text on overflow (Adatta testo all'area di riversamento)** — autofit mode that shrinks text as the box fills; never use (Ch02)
**Slide background fill** — shape fill showing the portion of the slide background beneath it; basis of the glass card (Ch03)
**Slide Master (Schema diapositiva)** — top-level slide holding everything that repeats: guides, fonts, colours, footer, layouts (Ch01)
**Slide Sorter** — thumbnail view for checking consistency across slides at the end of a job (Ch02, Ch05)
**Smart Animate** — Figma Slides' object-matching transition, no grouping needed (Ch04)
**Smart guides** — temporary alignment lines shown while placing objects (Ch02)
**SmartArt** — built-in diagrams; acceptable when chosen by content logic (process, cycle, relationship) and restyled (Ch02)
**Smooth Start / Smooth End** — easing options; always on for Fly In, off for constant-speed loops (Ch03)
**Speaker notes** — presenter-only text holding everything the slides don't say (Ch05)
**Split (Morsa)** — entrance effect used only on outline-only shapes and lines (Ch03)
**Staging motion** — animation that composes or decomposes the scene, e.g. a cover assembling (Ch03)
**State-per-slide** — each interface state becomes one slide and Morph interpolates between them (Ch03)
**Subtract** — Merge Shapes operation removing the second shape from the first; used for text masks and frames (Ch02)
**Theme colours** — the 12-slot colour scheme (Dark/Light 1–2, Accent 1–6, Hyperlink, Followed Hyperlink) used by all colour menus (Ch01)
**Theme fonts** — Heading and Body fonts set once in the Master (Ch01)
**Transition** — effect applied to the whole slide change (Ch03)
**Two-window setup** — audience window shared in a call while the presenter window with notes stays private (Ch05)
**Wheel (Spirale)** — entrance effect used with 1 spoke on an outline-only circle to draw a percentage ring (Ch03)
**Wipe (Cascata)** — entrance effect used to "draw" lines in the stroke direction (Ch03)
**With Previous** — animation start option running an item together with the previous one; delays count from the group's first item (Ch03)
